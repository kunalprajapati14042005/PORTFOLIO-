# Kunal Prajapati — Portfolio

Modern React + Vite portfolio redesign.

## Before publishing

1. Open `src/App.jsx`.
2. Replace `YOUR_EMAIL_HERE` with your real email address.
3. Replace the three project GitHub links with the actual repository URLs when you have them.
4. Replace the experience text with your real internship/company details once finalized.
5. Run `npm install` and `npm run dev` locally.
6. Commit and push to your existing GitHub repository. Vercel should automatically deploy the changes.

## Stack

- React
- Vite
- CSS
- Responsive design
- No additional runtime UI libraries required
